# Time_Series_Analysis_most_common_models
Walmart Weekly Sales Forecasting using Python
My project is Walmart weekly sales forecasting using Python. I took store and department-level sales data and aggregated it by date to create a weekly sales time series. I cleaned the data by removing duplicates, missing values and invalid sales values.

I then performed statistical diagnostics using ADF, KPSS, ACF, PACF and Ljung-Box tests to understand the time series. I also performed seasonal decomposition.

I compared four forecasting models: ARIMA, SARIMA, Holt-Winters and Prophet. I evaluated them using RMSE, MAE and MAPE. Prophet performed best because it had the lowest values for all three metrics.

From an MBA perspective, the forecast can help Walmart with inventory, procurement, workforce planning, sales targets and budgeting.
